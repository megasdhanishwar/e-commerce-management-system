# Evergreen — E-Commerce Management System

A responsive React + Vite + Tailwind CSS demo storefront with a green/light aesthetic.

## Run

```bash
npm install
npm run dev
```

Production build: `npm run build`.

## Admin demo

- Email: `admin@evergreen.in`
- Password: `Admin@123`

For a customer account, use Register. Cart, products, accounts and orders are stored in your browser's localStorage.

## Pages

Home, products with filters, product details, cart, checkout, login, registration, profile, order history and admin product CRUD.

## Notes

This is a **frontend-only demo**. Checkout simulates cash on delivery and does not process payments. Authentication and passwords are stored in localStorage for demonstration only and are **not secure for production**. Production deployments require server-side authentication, authorization, password hashing, payment integration and inventory validation. Product photos load from Unsplash and need internet access.
